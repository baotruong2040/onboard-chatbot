# Quyết định

- Giao diện ban đầu là terminal/console; Telegram làm sau.
- Dùng SQLite vì ứng dụng chạy cục bộ và dữ liệu demo nhỏ.
- Dùng OpenRouter cho cả embedding và LLM generation.
- Dùng cosine search trong ứng dụng, chưa cần cài vector database riêng.
- Test tự động đơn giản bằng fake client; smoke test API thật riêng.
- Bộ tri thức ban đầu chỉ là dữ liệu giả lập.
